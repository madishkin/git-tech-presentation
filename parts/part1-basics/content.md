# Тема: Внутреннее устройство и архитектура Git

## Слайд 1: Что такое Git и чем он отличается от SVN
- Git — распределенная система контроля версий (DVCS). Каждый разработчик имеет полную историю репозитория локально.
- Подход к данным: вместо хранения разницы между файлами (дельт) Git сохраняет **снапшоты (снимки)** всего проекта в конкретный момент времени.
- Целостность: каждый объект хешируется с помощью алгоритма SHA-1 (или SHA-256). Изменить файл без изменения его хеша невозможно.

## Слайд 2: Три состояния файлов и три дерева
- **Working Directory (Рабочая директория):** песочница с реальными файлами на диске.
- **Staging Area / Index (Область подготовки):** буфер, куда попадают файлы после `git add`. Формирует будущий коммит.
- **Git Repository / .git directory:** база данных объектов, где надежно сохранены метаданные и коммиты (`git commit`).

## Слайд 3: Базовые объекты Git
- **Blob (двоичный объект):** хранит только содержимое файла (без имени и прав доступа).
- **Tree (дерево):** директория, связывающая имена файлов с их blob-объектами и другими tree.
- **Commit:** снимок корневого дерева, метаданные (автор, время, комментарий) и ссылка на родительский коммит(ы).
- **HEAD:** указатель на текущую ветку или коммит, на котором мы находимся.
